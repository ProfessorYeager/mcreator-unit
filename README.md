# MCreator Minecraft Mod Unit · ECS2025

A single-page course companion site for the Exploratory Computer Science MCreator unit at Salem Public Schools. Built for a freshman cohort of 10 students over 5 weeks (~15 sessions, 54 min each).

## What this is

Students learn core software development concepts by building Minecraft mods with [MCreator](https://mcreator.net). The unit follows the full dev lifecycle:

**Design → Logic → Interface → Ship**

| Week | Topic | Sessions |
|------|-------|----------|
| 1 | Textures & Blocks | 3 (Tue–Thu) |
| 2 | Procedures & Logic | 4 (Tue–Fri) |
| 3 | GUIs & Inventory Slots | 4 (Tue–Fri) |
| 4 | Export, Install & Publish | 4 (Tue–Fri) |

Each session card includes what/why/how objectives, linked MCreator wiki resources, and PDF worksheet links.

## Deploying

This is a single `index.html` file with no dependencies or build step.

To host on GitHub Pages: go to **Settings → Pages → Source → main branch / root**.
