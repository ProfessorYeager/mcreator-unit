Week 2

Procedures & Logic

4 sessions
Tue – Fri
What
Attach a procedure to a block so something happens when a player interacts with it, with an if/else condition controlling the outcome.
Why
This is the leap from art to programming — students go from "what it looks like" to "what it does." Event-driven logic is the foundation of all software.
How
Open the procedure editor, wire a trigger (right-click, walk-over) to an action, then add a condition block to control behavior based on game state.
🔗 Resources

What
Store and track values using variables, then call one procedure from another to create compound, reusable behavior.
Why
State and reusability are two pillars of real coding. Students see why programmers break logic into pieces — and why that makes things more powerful, not less.
How
Create a counter variable, build a second procedure that reads and modifies it, then call one procedure from another to produce compound behavior.

Week 3

GUIs & Inventory Slots

4 sessions
Tue – Fri
What
Design a custom inventory screen with labeled slots for a block — like a crafting station, storage chest, or custom machine.
Why
GUIs are how users talk to software. Designing one teaches UI thinking and connects visual layout to backend logic — a pattern that applies everywhere in tech.
How
Open the GUI element builder, place slots and labels on the design canvas, link the GUI to a block, then open it in-game to verify the layout.

Week 4

Export, Install & Publish

4 sessions
Tue – Fri
What
Export the finished mod as a distributable .jar file and install it in a real Minecraft instance using NeoForge.
Why
"Shipping" software is its own skill, distinct from building it. Students experience the full development lifecycle and learn that deployment has real steps.
How
Click Export in MCreator, locate the .jar output, drop it into the NeoForge mods folder, and launch Minecraft to confirm it loads without errors.
1.In MCreator, click the Export button in the top toolbar. Enter your mod details and click Export — your .jar file is saved to a location you choose.
2.Install NeoForge (for Minecraft 1.20.2+) or Forge (for 1.20.1 and below) matching the exact version MCreator used. Find the version in MCreator's About window.
3.In the Minecraft Launcher, create a new Installation. Set the version to match your Forge/NeoForge install. Set a custom game directory to keep mods isolated (e.g. .minecraft/installations/mcreator-mods).
4.Launch the game once to generate the mods folder, then close it.
5.Navigate to your installation's mods folder and drag in your .jar file.
6.Launch again. If it reaches the main menu, your mod is installed. If it crashes, check for version mismatches or missing dependencies.
